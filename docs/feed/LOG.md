# Журнал фида: что записано и как это пересчитать

`log.json` — массив событий. Запись не правится, только дополняется: исправление
опубликованного — это новое событие, а не редактирование старого.

## Поля события

| Поле | Что это |
|---|---|
| `id` | порядковый номер, с единицы |
| `ts` | время публикации, UTC, ISO 8601 |
| `type` | тип события, см. ниже |
| `claim_id` | номер тезиса, например `001` |
| `card_id` | номер карточки внутри тезиса, например `001-1` |
| `actor_label` | как подписан автор карточки |
| `level` | `named` или `pseudonym` |
| `reality_source` | `автор сайта`, `знакомость` или `подпись Конституции` — только если это правда |
| `content_hash` | SHA-256 файла карточки, см. ниже |
| `prev_hash` | `content_hash` предыдущего события; у первого `null` |

Просмотры, клики и прочая посещаемость сюда **не пишутся**.

## Типы событий

Используются сейчас:

- `feed.verdict` — опубликована карточка с вердиктом по тезису
- `feed.challenge` — опубликована атака на строку тезиса
- `feed.retract` — автор отозвал свою карточку

Зарезервированы для других подпроектов, событий пока нет и создавать их не надо:

- `ninja.report`
- `wiki.claim`

## content_hash

Хэш считается от **байтов опубликованного файла карточки** целиком.

Это значит, что любая правка файла — включая исправление опечатки или отступа —
ломает хэш. Так и задумано: опубликованное не переписывается. Изменилось
содержимое — появляется новое событие с новым хэшем, старое остаётся на месте.

```python
import hashlib, pathlib
print(hashlib.sha256(pathlib.Path("claims/001.html").read_bytes()).hexdigest())
```

## Проверить цепочку

Только стандартная библиотека Python. Ничего ставить не нужно.

```python
import hashlib, json, pathlib

FILES = {"001-1": "claims/001.html"}          # card_id → файл карточки

log = json.loads(pathlib.Path("log.json").read_text(encoding="utf-8"))
prev = None
ok = True

for e in log:
    path = FILES.get(e["card_id"])
    if path is None:
        print(f'#{e["id"]}: файл карточки {e["card_id"]} не сопоставлен'); ok = False; continue

    got = hashlib.sha256(pathlib.Path(path).read_bytes()).hexdigest()
    if got != e["content_hash"]:
        print(f'#{e["id"]}: содержимое изменилось\n  в журнале {e["content_hash"]}\n  сейчас    {got}')
        ok = False

    if e["prev_hash"] != prev:
        print(f'#{e["id"]}: разрыв цепочки — ожидался prev_hash {prev}, записан {e["prev_hash"]}')
        ok = False

    prev = e["content_hash"]

print("цепочка цела" if ok else "цепочка нарушена")
```

Запускать из папки `docs/feed/`.

## Как добавить событие

1. Опубликовать файл карточки.
2. Посчитать его `content_hash`.
3. Дописать событие в конец `log.json`: `id` на единицу больше предыдущего,
   `prev_hash` равен `content_hash` предыдущего события.
4. Добавить пару `card_id → файл` в `FILES` в скрипте выше.
5. Прогнать проверку.

Порядок важен: хэш считается от уже опубликованного файла, а не от черновика.
