# Платформа на практике: деятельность, проекты, веб, самомасштабируемость

> Конкретика поверх общей структуры ([WHITEPAPER.md](./WHITEPAPER.md)): чем реально занимается платформа и участники, какие проекты продвигаются, как выглядят экраны и в чём именно самомасштабируемость.

---

## Чем конкретно занимается платформа

Место, где верифицированные люди коллективно делают три вещи:

1. **Решают** — голосуют по глобальным и локальным вопросам (постоянный референдум).
2. **Продвигают инициативы** — запускают и поддерживают конкретные гражданские проекты голосами и деньгами (квадратичное финансирование).
3. **Подтверждают** — друг друга (гильдии) и свой вклад (работы, репутация).

Плюс паспорт доверия и анти-бот значок, которые работают **за пределами** платформы.

---

## Какие проекты и инициативы продвигаются

Рамка отбора: прозрачность, антикоррупция, права человека, общественные блага, профессиональная честность — всё, что соответствует «честность сильнее власти».

| Категория | Конкретный пример |
|---|---|
| Глобальные референдумы | «Должны ли алгоритмы соцсетей быть открыты для аудита?» |
| Открытый бюджет | «Построчный бюджет мэрии Тбилиси» |
| Прозрачность власти | Запрос раскрытия финансов конкретного чиновника |
| Краудфандинг общественных благ | Квадратичный сбор на школу / чистую воду |
| Профстандарты | Гильдия врачей утверждает стандарт верификации диплома |
| Анти-коррупция | Анонимный сигнал с доказательствами + защита заявителя |
| Авторство | Художник публикует работу как NFT с роялти |

---

## Что делают участники (конкретные действия)

- Верифицируются один раз → получают паспорт доверия и анти-бот значок.
- Подписывают Конституцию.
- Голосуют в Вопросе дня; предлагают свои вопросы.
- Запускают инициативы и поддерживают чужие (голосом и деньгами).
- Верифицируют коллег в гильдиях.
- Публикуют работы как NFT.
- Используют значок/вход на внешних площадках.
- Приводят людей (рефералы).

### День из жизни

- **Мария, Грузия (обычный человек):** утром голосует в Вопросе дня (+5 WORLD), видит локальную инициативу «открытый бюджет мэрии», подписывает, шарит другу (реферал +25). Значок «проверенный человек» ставит в bio Instagram — против ботов и самозванцев.
- **Д-р Самир, ОАЭ (гильдия):** подтверждает двух новых врачей; его verified-MD статус используется на медицинской платформе-партнёре.
- **Аноним под репрессивным режимом:** анонимно сообщает о нарушении с доказательствами — голос засчитан, личность скрыта, участие оплачено.
- **Художник (создатель):** грузит работу как NFT (прошла ИИ-проверку уникальности), продаёт за SOL, получает роялти с каждой перепродажи.

## Как это выглядит на вебе (ключевые экраны)

1. **Главная** — слоган, живой счётчик подписей, кнопка «Подписываю», превью сегодняшнего вопроса.
2. **Конституция** — 19 статей (0–18), кнопка подписи, «стена подписантов» + карта мира.
3. **Кабинет** — карточка паспорта (значок + скор), вопрос дня, инициативы рядом, баланс WORLD.
4. **Вопрос дня** — вопрос, варианты, результаты на карте в реальном времени, ветка обсуждения.
5. **Инициативы** — каталог проектов: запустить / поддержать деньгами / присоединиться / следить за прогрессом.
6. **Профиль** `/u/имя` — значок, вклад, NFT-портфолио, переключатель режима видимости.
7. **Кошелёк** — WORLD, история, вывод.

> На старте (Этап 0) живут только экраны 1–2. Остальные добавляются по дорожной карте.

## Сквозной сценарий на практике (end-to-end)

1. Человек видит у друга значок «проверенный человек» в соцсети → переходит.
2. Читает Конституцию → подписывает (email, без крипты).
3. Верифицируется в один клик через World ID → получает значок и паспорт.
4. Голосует в Вопросе дня → +5 WORLD, видит результат на карте.
5. Находит инициативу «открытый бюджет своего города» → поддерживает, зовёт соседей.
6. Ставит значок обратно в свою соцсеть → приводит новых людей.

Круг замкнулся: пришёл извне → стал узлом → привёл следующих.

## В чём самомасштабируемость (механика)

Суть: **затраты роста несут сами участники, потому что им выгодно растить сеть.** Платформа даёт рельсы — участники генерируют рост.

| Рычаг | Кто двигает рост | Почему компаундится |
|---|---|---|
| Гильдии | Врачи верифицируют врачей | Ёмкость верификации растёт с числом людей, не упирается в оператора |
| Инициативы | Каждый проект тянет тех, кому он важен | Они верифицируются ради участия → база растёт |
| Анти-бот значок | Чужие площадки шлют своих юзеров верифицироваться | Рост приходит извне, оплачен чужой болью |
| Основатели страны | Статус навсегда → стимул звать | Гонка ранних расширяет географию |
| Контент (NFT, инициативы) | Создают пользователи | Больше людей → больше контента → больше притяжения |
| Рефералы через траст | Привёл реальных людей → растёт узел и доход | Прямой денежный стимул к росту |
| Открытый API | Разработчики строят приложения поверх | Каждое приложение — новый канал, который оператор не строил |

> Оператор не производит рост вручную — он его включает. Каждый участник, расширяя сеть, увеличивает ценность и для себя, и для всех. Это и есть самомасштабируемость: рост оплачивается теми, кто от него выигрывает.

## Итог в одну фразу

> Платформа даёт рельсы — решать, продвигать и подтверждать. Контент, верификации, инициативы, деньги и новых людей приносят сами участники, потому что растить сеть им выгодно.
