## СУТЬ ПРОЕКТА

Первая глобальная инфраструктура доверия для человечества. ООН не справляется. Правительства ведут агрессивную политику. Люди не имеют реального голоса. Технологии впервые позволяют это исправить.

## ПИТЧ ПО АУДИТОРИЯМ

**Для обычного человека:**

> "Твой голос впервые в истории имеет реальный верифицированный вес."

Как это работает:

- Верифицируешься через Polygon ID — ты реальный человек
- Получаешь траст скор на основе своей жизни
- Голосуешь по глобальным вопросам
- Твой голос виден и считается
- Зарабатываешь WORLD токен за участие

**Для политика:**

> "Система которая делает честность выгоднее власти."

Как это работает:

- Твоя публичность уже даёт высокий базовый скор
- Прозрачность финансов поднимает скор ещё выше
- Добровольный уход = Исторический статус + защита + финансовые бенефиты
- Закрытость и война = этический штраф -90%
- Уйти выгоднее чем держаться

**Для инвестора:**

> "Инфраструктура доверия для 8 миллиардов людей."

Как это работает:

- Протокол под всем — как TCP/IP для интернета
- API который используют банки, правительства, HR платформы
- Два токена: WORLD (утилити) + TRUST (репутация)
- Сетевой эффект: больше людей = ценнее для всех
- Рынок: замена визовых систем, KYC, нострификации

## ТРАСТ СКОР 0-1000

Пять параметров:

```
Публичность      0-200
Профессионализм  0-200
Вклад            0-200
Этика            0-200 (единственный который уходит в минус)
Активность       0-200
```

Режимы пользователя:

- Публичный → максимальный скор, всё видно
- Частичный → ты выбираешь что кому видно
- Анонимный → только ZKP доказательство, скор сохраняется

Нельзя скрыть никогда:

- Обвинения МУС
- Международные санкции
- Этический штраф

## САМОПОСТРОЕНИЕ СИСТЕМЫ

Платформа строится участниками:

- Верифицировался → система надёжнее
- Загрузил работу → контент вырос
- Проголосовал → данные точнее
- Привёл друга → сеть расширилась

Механизмы роста:

- Реферальная система через траст
- Локальные амбассадоры (высокий скор = узел сети)
- Профессиональные гильдии (врачи верифицируют врачей)
- Первые 100 в каждой стране = основатели страны навсегда
