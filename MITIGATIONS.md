# Решения слабых мест: технические средства, бизнес-модель, бесплатные инструменты

> Ответ на [OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md): как закрыть каждую дыру. На каждую — технический патч и/или ход в бизнес-модели. Почти весь критичный стек закрывается бесплатными open-source инструментами.

---

## Главное: критичный стек — бесплатный и открытый

| Задача | Бесплатный / open-source инструмент |
|---|---|
| Уникальность человека | World ID · BrightID · Idena · Semaphore |
| ZK / выборочное раскрытие | Polygon ID (Privado ID) · circom + snarkjs · SD-JWT · BBS+ · zk-kit |
| Голосование без подкупа и принуждения | MACI (Minimal Anti-Collusion Infrastructure) |
| Квадратичное голосование / финансирование | MACI · clr.fund |
| Восстановление доступа (social recovery) | ERC-4337 · Safe · Web3Auth (free tier) |
| Агрегатор скоров против Sybil | Gitcoin / Human Passport |
| Хранилище | IPFS · Ceramic · Arweave |
| Оракулы (санкции, МУС) | Chainlink |
| Бесплатные деньги на запуск | Gitcoin Grants · Optimism RetroPGF · экосистемные гранты |

## ТОП-5 экзистенциальных

### 1. Социальный кредит / надзор → закрываем в коде

- Скор **не запрашивается публично** по умолчанию. Каждое раскрытие требует криптографического согласия владельца (Статья 15 в коде).
- Раскрывается **предикат** через ZK («верифицирован» / «скор > X»), а не вся карточка.
- Нет API «поиск по имени», нет перечислимого реестра → массовую слежку построить нельзя.
- Бизнес/право: условия лицензии и статья Конституции запрещают применение как соцрейтинг; отказ от B2G-контрактов с принудительным использованием; нейтральная юрисдикция.
- **Бесплатно:** Polygon ID, W3C Verifiable Credentials, BBS+ (selective disclosure).

### 2. Продажа / аренда аккаунтов → техника + экономика

- **Периодический liveness** в случайные моменты (особенно перед важными голосами) — арендатор не пройдёт.
- Модель **Idena** построена на синхронных церемониях — аккаунт физически нельзя сдать.
- Ключи в secure enclave устройства; граф-анализ «одно устройство — много аккаунтов».
- Экономика: продал логин — теряешь непередаваемый TRUST → смысл сделки падает.
- **Бесплатно:** Idena, World ID (периодическая проверка), Semaphore.

### 3. На что влияют голоса → две камеры власти (бизнес-логика)

- **Внутренняя власть (жёсткая):** платформа, казна, правила — исполняется кодом DAO. Голос обязателен.
- **Внешняя власть (мягкая):** «Вопрос дня» по мировым темам — постоянный референдум легитимности: видимый глобальный консенсус + давление + медиа-вес.
- Внешнее принуждение — только где государство/орг **добровольно** подключились.
- Честно: внутри — твёрдая власть, снаружи — мягкая сила.

### 4. Этический штраф = чья мораль → сужаем и регламентируем

- Только **узкие, объективно проверяемые** триггеры (приговор МУС, листинг санкций, ончейн-доказанное мошенничество) — не размытое «неэтично».
- **Совпадение нескольких независимых источников** → меньше политизации.
- Спорное показывается как «оспаривается / на проверке», не как вина.
- Апелляция в **случайную панель** (жребий), отмена восстанавливает репутацию.
- Честно: мораль объективной не сделать — делаем объективными триггеры.

### 5. B2B-спрос → лестница клиентов + проверка ДО постройки

- Слово «KYC» из питча убрано: банк юридически обязан проводить собственный KYC — продажа «замены» это многолетний комплаенс-поход, а не ранний рынок.
- **Лестница:** крипто-нативные (DAO, минты, квадратичное финансирование — боль реальна, платят сегодня) → web2 с ботами (дейтинг, маркетплейсы, билеты, комьюнити — продаём proof-of-human) → регулируемые (банки — год 3+, только как дополнительный сигнал в партнёрстве с лицензированными провайдерами).
- Де-риск: **5 интервью с DAO/площадками до разработки**; трое просят демо — гипотеза жива.

## Остальные слабые места

| Слабое место | Решение | Бесплатные инструменты |
|---|---|---|
| Тирания большинства | Две палаты (большинство людей **и** стран) + квадратичное голосование + субсидиарность | MACI |
| Принуждение к голосу | Переголосование (последний голос считается, как в Эстонии) + receipt-freeness | MACI |
| Дедупликация между провайдерами | Ступенчатая подлинность: вес действия определяет силу проверки (1 якорь → подпись; 2+ якоря + liveness → голос; гильдия/церемония → управление). Своя сеть верификации со временем становится фундаментом — инверсия зависимости | World ID, BrightID, Idena, Semaphore |
| GDPR vs неизменяемость | Персональные данные off-chain у пользователя; на чейне только хеши. Удаление off-chain → ончейн-хеш становится бессмысленным | Ceramic, IPFS+шифрование, Polygon ID |
| Холодный старт | Ценность при N=1: значок «живой человек» против ботов на чужих площадках; «Вход через WorldConstitution» как анти-бот; целевое сообщество с болью (DAO) | World ID, Sign-in SDK |
| Награды до выручки | Гранты на публичное благо + ранние награды статусные (бейджи основателей, стоят 0) | Gitcoin Grants, Optimism RetroPGF |
| Регуляторика токена | Старт без токена; ввод позже комплаентно через швейцарский фонд + юр-заключение | — |
| Восстановление / наследование | Social recovery (гардианы); наследуются переносимые активы (WORLD/NFT), TRUST гаснет со смертью | ERC-4337, Safe |
| Инклюзия | Социальное поручительство без документов + амбассадоры офлайн + PWA для слабых устройств | BrightID, PWA |
| Дискриминация по скору | Предикатное раскрытие + «пол прав»: базовые права не зависят от скора | Polygon ID |
| Явка / кворум | Минимальный кворум для обязательных решений + жидкая демократия (делегирование голоса) | — |
| Легитимность генезиса | Конституция v0 «временная», ратифицируется первыми подписантами; власть основателей с публичным сроком истечения | — |
| Юр-статус конституции | Не претендуем на суверенитет; добровольная хартия (моральная сила, как Декларация ООН); «принятие» = интеграция API | — |
| Оракул централизован | Децентрализованные оракулы + несколько источников + прозрачность | Chainlink |
| Масштаб / стоимость | Действия off-chain, на чейн только доказательства; L2 / Solana низкие комиссии | Solana, zk-rollups |
| Нейтральность миссии | Враг — **коррупция** (популярно везде), а не режимы; нейтральная юрисдикция; пилоты в дружественных странах | — |

## Вывод

- Почти каждая экзистенциальная дыра имеет **конкретное решение** — техническое, в бизнес-модели, или оба.
- **Бесплатных open-source инструментов достаточно**, чтобы собрать критичный стек без закупки проприетарных решений.
- Главный приоритет — встроить защиту от соцрейтинга (раскрытие только по согласию, предикаты вместо карточки) **с первого дня**: это определяет, добро мы строим или зло.
