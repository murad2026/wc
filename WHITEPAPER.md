# WorldConstitution.org — описание проекта (Whitepaper)

> # Честность сильнее власти.
> *Открытость рождает доверие. Доверие строит будущее. Инструмент — уже здесь.*

Единое описание проекта: возможности, старт, финмодель, рост, инструменты, защита и бенефиты — поэтапно. Сводит вместе все документы репозитория (см. [README.md](./README.md)).

---

## 1. Что это

Первая глобальная **инфраструктура доверия** — мета-слой, который подтверждает, что человек реален и уникален, даёт ему репутацию, которой он владеет сам, и голос, имеющий проверяемый вес. Не новое государство и не очередная соцсеть — **протокол доверия под всем остальным, как TCP/IP под интернетом.**

Не декларация — работающий код.

## 2. Проблема

Существующие институты не справляются с защитой человека и будущих поколений. Власть скрытна, у людей нет верифицированного голоса, репутация принадлежит платформам, а не людям. Технологии впервые позволяют это исправить.

## 3. Решение в одном абзаце

Человек подтверждает свою уникальность через уже работающие сервисы, владеет непередаваемой репутацией, голосует с реальным весом, подписывает Всемирную Конституцию и зарабатывает на участии. При этом власть и деньги самой системы прозрачны и не лежат под единоличной рукой.

---

## 4. Архитектурный фундамент — два столпа

1. **Независимость развития** — система растёт и строится сама, без центрального управления; её нельзя выключить, купить или захватить.
2. **Подлинность личности** — 100% действий защищены проверкой подлинности, соразмерной весу действия (ступенчатая подлинность: якорь → подпись; 2+ якоря → голос; гильдия → управление).

Они работают **только вместе**: децентрализация без подлинности → захват ботами; подлинность без децентрализации → слежка. Вместе — то, чего нет ни у Worldcoin (централизован), ни у классических DAO (тонут в ботах). Подробно — [ARCHITECTURE.md](./ARCHITECTURE.md).

## 5. Технические возможности (какие инструменты создаются)

| Инструмент | Что делает | Практическое применение |
|---|---|---|
| **Паспорт доверия** | Репутация 0–1000 + статус «верифицирован», с ZK-раскрытием | Один паспорт вместо сотни проверок |
| **Proof-of-personhood агрегатор** | Сшивает World ID / BrightID / Polygon ID в одну уникальность | Защита «1 человек = 1 голос», анти-Sybil |
| **Гильдии (verified-professional)** | Профессионалы верифицируют профессионалов — наш собственный слой подлинности | verified-MD для медплатформ, verified-engineer для найма |
| **Анти-бот значок** | Доказательство «я живой человек» | Используется на чужих площадках (соцсети, маркетплейсы, дейтинг) |
| **Sign-in with WorldConstitution** | Вход без ботов для других приложений | Анти-Sybil-as-a-service для DAO, сервисов |
| **Голосование без подкупа** | Receipt-free, квадратичное (MACI) | Честные референдумы, нельзя купить голос |
| **Конституция ончейн** | Неизменяемые подписи | Глобальная петиция/хартия, проверяемая |
| **NFT-портфолио** | Авторство + ИИ-проверка уникальности + роялти | Доход создателям, защита авторства |
| **Открытый API** | Проверка статуса/предиката по согласию | Банки, HR, госуслуги, платформы |
| **Прозрачная казна** | Каждый поток виден, целевые статьи | Доверие к финансам проекта |

Почти весь стек — **бесплатные open-source инструменты** (см. [MITIGATIONS.md](./MITIGATIONS.md)).

## 6. Социальные возможности

- **Реальный голос** — постоянный референдум легитимности по мировым темам.
- **Прозрачность власти** — чем публичнее должность, тем прозрачнее финансы (Статья 3).
- **Достойный уход лидеров** — Статья 5: честная передача власти выгоднее удержания.
- **Защита уязвимых** — анонимный режим для людей под репрессивными режимами.
- **Профессиональные гильдии** — врачи верят врачам, поверх границ.
- **Свобода передвижения** — единый цифровой паспорт доверия (Статья 13).

## 7. Как начинается (старт и холодный старт)

**Проблема холодного старта** честно решена через ценность при N=1: продукт полезен ещё до того, как сеть большая.

- **Этап 0 — буквально 3 страницы:** Главная (миссия + 4 бенефита) + Конституция + кнопка «Подписываю» (email/соцсети, без крипты). Зашёл → прочитал → подписал.
- **Крючок одиночки:** анти-бот значок «я живой человек», который можно показать **на чужих площадках** уже сейчас; подпись Конституции как вирусный акт причастности.
- **Первое сообщество:** целимся в тех, у кого боль уже есть — DAO и крипто-сообщества, которым нужна Sybil-защита; затем дружественные страны-пилоты (Эстония, Грузия, Уругвай, ОАЭ, Руанда).

## 8. Как генерируется финансовая модель

**Источники по этапам (см. [FINANCE.md](./FINANCE.md)):**

| Этап | Источник денег |
|---|---|
| 0–1 | Гранты на публичное благо (Gitcoin, Optimism RetroPGF) + донаты |
| 2–3 | B2B proof-of-human + verified-professional (гильдии) + B2C-подписки + % с NFT |
| 3+ | Токен WORLD — только когда есть что капитализировать |

**Принципы:** прозрачность (публичная казна в реальном времени), целевое использование (каждый расход помечен статьёй), казной не владеет один (мультисиг → DAO).

**Устойчивость, не пирамида:** награды платятся из **реальной выручки**, а не из печати токена. Цель Этапа 4 — самоокупаемость.

**Лестница клиентов:** крипто-нативные (DAO, минты — платят уже сегодня) → web2 с болью от ботов (дейтинг, маркетплейсы, билеты) → регулируемые (банки — год 3+, только в партнёрстве с лицензированными провайдерами). Проверяем интервью и пилотами **до** полной разработки.

**Доход основателей:** роялти 7% выручки протокола (двое основателей, поровну) — открыто с первого дня, зашито ончейн, без прав управления. Доход отвязан от власти, поэтому передача управления сообществу не страшна и не убыточна (см. [FINANCE.md](./FINANCE.md)).

## 9. Как публика растёт сама и почему

**Маховик самопостроения** — каждое действие повышает ценность для всех:

```
Верифицировался → сеть надёжнее
Загрузил работу → контента больше
Проголосовал    → данные точнее
Привёл человека → сеть шире
        ↓
Система ценнее → приходит больше людей → маховик ускоряется
```

**Почему растёт сама:**
- **Сетевой эффект** — чем больше верифицированных людей, тем ценнее паспорт и голос для каждого.
- **Рефералы через траст** — привёл реальных людей → растёт твой узел и доход.
- **Гильдии** — профессионалы втягивают профессионалов (врачи верифицируют врачей).
- **Основатели страны** — первые 100 в каждой стране = статус навсегда → гонка ранних.
- **Wedge на чужих площадках** — анти-бот значок приводит людей извне, ещё до того как они узнали о Конституции.

Подробно — [ARCHITECTURE.md](./ARCHITECTURE.md), [SCORING.md](./SCORING.md).

## 10. Как защищены обычные члены

- **Анонимность** — полноценное участие и заработок под псевдонимом; голос анонима равен голосу публичного.
- **Данные off-chain** у владельца; на чейне только хеши → право на забвение работает (GDPR).
- **Раскрытие только по согласию** — нет API «поиск по имени», нет перечислимого реестра; раскрывается ZK-предикат («верифицирован» / «скор > X»), а не вся карточка → **массовый соцрейтинг построить нельзя.**
- **Базовые права не зависят от скора** — «пол прав».
- **Голосование без подкупа и принуждения** — receipt-freeness + переголосование (последний голос считается).
- **Этический штраф узкий и оспоримый** — только проверяемые триггеры, апелляция случайной панелью.

## 11. Как защищены создатели

- **Нейтральная юрисдикция** — швейцарский/эстонский фонд; позиционирование как **public good**, а не бизнес против режимов.
- **Не претендуем на суверенитет** — это добровольная **моральная хартия** (как Декларация ООН), а не захват власти → меньше юридической атаки.
- **Прогрессивная децентрализация** — контроль передаётся сети по публичному графику заката основателей (founder sunset, см. [ARCHITECTURE.md](./ARCHITECTURE.md)); основатели не остаются единоличными владельцами → снимает личную ответственность и риск «захвата основателями».
- **Роялти вместо контроля** — доход основателей (7%) не зависит от власти, поэтому нет мотива тайно держаться за неё.
- **Форкабельность и открытый код** — протоколом нельзя владеть; это защита и от давления, и от обвинений в монополии.
- **Антикоррупционная рамка миссии** — враг сформулирован как коррупция (популярно везде), а не конкретные страны.

## 12. Бенефиты

**Для обычного члена:**
- Один паспорт доверия вместо сотни проверок.
- Репутация, которой владеешь сам — не купить, не передать, не отнять.
- Голос с реальным весом.
- **За участие — репутация и статус; деньги — за созданную ценность:** SOL с продаж NFT + роялти навсегда; 50% от оплаты, когда внешний сервис запросил твой статус; оплата работы верификатора гильдии. (см. [SCORING.md](./SCORING.md))

**Для создателей / ранних участников:**
- **Статус основателя** — первые 100 в каждой стране, навсегда.
- Ранний узел сети = наибольший сетевой вес и отдача.
- Репутация первопроходца + (на Этапе 3+) доля в экосистеме токена.
- Исторический статус для лидеров, добровольно сделавших систему прозрачнее (Статья 5).

## 13. Поэтапно: от создания до зрелости

| Этап | Срок | Что построено | Кто приходит | Деньги | Какие риски сняты |
|---|---|---|---|---|---|
| **0. Подпись** | 0–1 мес | 3 страницы: миссия + Конституция + подпись | Идейные ранние, крипто-сообщества | Гранты/донаты | Проверка гипотезы спроса |
| **1. Паспорт** | 1–3 мес | Профиль + верификация в 1 клик + анти-бот значок | Те, кому нужен анти-бот статус | Гранты | Подлинность, холодный старт (N=1) |
| **2. Голос** | 3–6 мес | Вопрос дня + первый B2B-API | Активные граждане, первые B2B | Первая выручка B2B | Спрос B2B, вовлечение |
| **3. Репутация и экономика** | 6–12 мес | Скор 0–1000 + токен WORLD + расширенный API | Массовый приток, гильдии | Подписки + API + NFT | Монетизация, устойчивость |
| **4. Самоуправление** | 1–2+ года | DAO + ончейн-казна + поправки + статус лидеров | Институты, правительства | Самоокупаемость | Децентрализация, независимость |

**Правило перехода:** не идём на следующий этап, пока текущий не достиг метрики. Сложность добавляется только когда заслужена спросом ([PRINCIPLES.md](./PRINCIPLES.md), [ROADMAP.md](./ROADMAP.md)).

## 14. Честный статус (что есть что)

- **Решено по дизайну:** защита от соцрейтинга, анонимный заработок, прозрачная казна, антиподкуп-голосование, GDPR-паттерн — все имеют конкретные технические/бизнес-решения и бесплатные инструменты.
- **Траектория (не на старте):** полная децентрализация, DAO, токен, ончейн-казна — приходят по этапам.
- **Гипотезы для проверки:** B2B-готовность платить, скорость роста публики — проверяются пилотами до больших вложений.

> Не декларация — работающий код. Мы строим то, что можно потрогать на каждом этапе, и честно показываем, что ещё предстоит доказать.
